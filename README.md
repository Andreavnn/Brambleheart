# Brambleheart TTRPG — Beta 0.19

Brambleheart is a Vue 3 + TypeScript + Vite + Vue Router tabletop companion application.

Beta 0.19 is a presentation-consistency and Rules-structure pass built on Beta 0.18 and its approval/Level Up reliability hotfix. It concentrates on theme depth, Character Sheet containment, shared card styling, functional Rules parent pages, Anthro Mundas/species presentation, Talent consolidation, Watcher consistency, and reusable Ability targeting.

## Main views

- Welcome / Splash
- Character List
- Guided Character Creation
- Character Level Up
- Rules / Rule Reader
- Rhythm Engine — Character Sheet and Dice Roller
- Settings
- Site Changelog

## Beta 0.19 focus

- Swaps Healer and Trickster palettes and establishes darker structural shells behind lighter foreground cards across themes.
- Refines Skullfen Ruins positioning, Donation/Reset Data Settings presentation, and themed separator colors.
- Places Character Sheet before Dice Roller, adds Character Detail, improves Dice Roller spacing, and prevents narrow-screen sheet overflow.
- Standardizes reusable content boxes around the established Species Trait card language.
- Adds functional chapter overview pages for Rules breadcrumbs and limits Anthro Mundas banners to the correct in-body position.
- Places Lore fluff above spells and removes Lore-name eyebrow text from spell title bars.
- Consolidates Movement, Survival, and Social Talents into Utility.
- Normalizes Watcher monster family/direct-link presentation.
- Renames Area of Effect to Ability Targeting, adds Combat Range/Touch, and generalizes grid targeting for Abilities.
- Combines Initiative, rounds, turns, performing Abilities, and Mana into one Rounds & Turns page.
- Rebuilds Species Rules intros with identity/quote and Species art side by side, with lore beneath.
- Retains explicit Incomplete / Unapproved / Approved character status and Approved-only Level Up behavior.

## Runtime

- Node.js 22 or newer
- Vue 3 / TypeScript / Vite
