# Brambleheart Beta 0.42 Patch Notes

Baseline: Beta 0.41.0, matching GitHub main commit `45aaa1aefca2844736dc9936597f268f6fa3ae63`.

- Normalized all mundane weapon damage, qualities, weights, and prices to the locked Beta 0.42 equipment table.
- Normalized armor and shield Guts, Mana Syphon, Might, weight, and pricing; replaced Stealth Penalty/Condition with Armor Penalty.
- Armor Penalty now reduces Speed (minimum 1) and applies the same negative condition to Whisperster Skill Checks; Steady Pace mitigates only its Speed component.
- Migrated current Skill naming to Whisperster, Tradeskill, Tradeskill (Blacksmithing), and Bondcraft while preserving legacy saved-name aliases only at normalization boundaries.
- Rebalanced Culture skill grants to exactly two Rank +1 grants and normalized key Heritage/Cultural Trait rules to the current rule grammar.
- Removed the Shield/Trinket slot relationship; characters now have two independent Trinket positions.
- Kept Adventure Kit contents visible on Review and the Rhythm Engine character sheet when the kit is retained.
- Reused one Equipment & Gear shop component in Character Creation and Level Up; moved Cloak of Windweave to Traveler’s Gear.
- Corrected weapon profile parsing so Damage remains in the Damage column rather than becoming a property pill.
- Added the Encounter Builder placeholder after Dice Roller in the Rhythm Engine.
- Updated News with Discord and Share panels and made the site logo navigate to News.
- Reordered Display, Data & Content, and Changelog & Updates settings to the requested physical DOM order.
- Updated the Abilities layout preview with centered type pills, flow arrows, the revised Ability Example and Reactive example, Basic Core Abilities, and corrected accent borders.
- Standardized Enhance terminology and removed individual Talent category labels while retaining categories for browsing/grouping.
- Condensed update history conservatively by removing superseded duplicate notes while retaining the latest statement of each change.

Rule Updates: v0.06. Site build: Beta 0.42.
