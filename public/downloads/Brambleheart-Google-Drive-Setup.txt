BRAMBLEHEART GOOGLE DRIVE CHARACTER SYNC SETUP
Beta 0.27

OVERVIEW
Brambleheart's Google Drive Character Sync is local-first and manually triggered.

- Your characters continue to be stored locally on the device while Brambleheart is running.
- Brambleheart does NOT poll Google Drive in the background.
- Google Drive is contacted only when you explicitly Link Folder, Update from Drive, or Upload Local.
- Brambleheart searches only the exact linked folder. It does not recurse into subfolders.
- Only files whose names end in _BH.json are considered character-sync files.
- One sync folder is limited to 250 Brambleheart character files to keep manual updates bounded and predictable.
- Character identity is determined by the internal Brambleheart character ID, not by the filename.

IMPORTANT GOOGLE DRIVE REQUIREMENT
Two-way service-account sync requires the Brambleheart folder to be inside a Google Workspace Shared Drive.
A normal personal My Drive folder cannot be used for full two-way sync because a Google service account cannot own newly created My Drive files.

The Brambleheart service account should be shared directly to ONLY the exact Brambleheart folder. Do not add the service account as a member of the entire Shared Drive unless you deliberately want it to have broader Drive access.

A Shared Drive administrator may need to allow external sharing before the service-account address can be added to the folder.

============================================================
PART 1 - ONE-TIME SETUP FOR THE BRAMBLEHEART SITE OWNER
============================================================

This section is only for the person who deploys Brambleheart. Normal players should begin with Part 2 after the site owner has configured Google Drive sync.

1. Create or select a Google Cloud project for Brambleheart.

2. Enable the Google Drive API for that project.

3. Create a Google Cloud service account dedicated to Brambleheart character sync.
   - Do not reuse a personal Google account.
   - Give the service account no unrelated Google Cloud permissions.

4. Create a JSON key for that service account and download it to a secure administrator device.
   The JSON key contains the service-account email address and private key.

5. In the Vercel project for Brambleheart, create these Environment Variables:

   BH_DRIVE_SERVICE_ACCOUNT_EMAIL
   Value: the service account's client_email value.

   BH_DRIVE_SERVICE_ACCOUNT_PRIVATE_KEY
   Value: the service account's private_key value.
   Store the complete private key, including BEGIN PRIVATE KEY and END PRIVATE KEY.
   Vercel may store it as a multiline value. Brambleheart also accepts literal \n line breaks.

   BH_DRIVE_LINK_SECRET
   Value: a long, random, private secret used to sign linked-folder tokens.
   Recommended: at least 32 random bytes / 64 hexadecimal characters.

6. Never place the service-account JSON key, private key, or BH_DRIVE_LINK_SECRET in GitHub, source files, browser code, or downloadable files.
   These values belong only in Vercel Environment Variables.

7. Redeploy Brambleheart after adding or changing the environment variables.

8. Open Brambleheart > Settings > Data & Content > Character Data.
   The Service Account row should display the configured service-account email address.

============================================================
PART 2 - CREATE AND LINK A CHARACTER SYNC FOLDER
============================================================

1. In Google Drive, create a folder INSIDE a Google Workspace Shared Drive.
   A suggested name is:

   Brambleheart Characters

2. Share ONLY that exact folder directly with the service-account email shown in:

   Brambleheart > Settings > Data & Content > Character Data

3. Give the service account an edit-capable permission that can add and edit files in that folder.
   Depending on your Google Workspace/Shared Drive configuration, the wording may be Editor, Contributor, Content Manager, or an equivalent edit-capable role.

   Do not make the service account a member of the entire Shared Drive unless broader access is intentional.

4. In Brambleheart, open Settings > Data & Content > Character Data.

5. Find Folder Link Code and copy the complete line shown by Brambleheart. It will look similar to:

   BH-LINK:BH-XXXXXXXXXXXXXXXXXXXXXXXX

6. In Google Drive, open the linked folder's Details and edit its Description.
   Add the exact BH-LINK line as its own line in the folder description.

   Do not add extra spaces inside the code. The BH-LINK line is temporary: after a successful link, Brambleheart removes that line automatically and writes a private Drive application property used to verify future sync requests. That private property is not shown as normal folder-description text.

7. Copy the Google Drive URL for that exact folder.
   It normally looks like:

   https://drive.google.com/drive/folders/FOLDER_ID

8. Paste that URL into Shared Drive Folder Link in Brambleheart.

9. Click Link Folder.

10. Brambleheart verifies all of the following before accepting the link:
    - the service account can access the folder;
    - the link points to a folder;
    - the folder belongs to a Shared Drive;
    - the service account can add and edit files there; and
    - the folder description contains the exact temporary BH-LINK code.

11. After the link succeeds, Brambleheart removes the BH-LINK line from the folder description automatically. The folder keeps a private Brambleheart application pairing property instead.

If any check fails, Brambleheart leaves the current local character data unchanged.

============================================================
PART 3 - UPLOAD LOCAL CHARACTERS TO DRIVE
============================================================

1. Open Settings > Data & Content > Character Data.
2. Confirm the desired Shared Drive folder is linked.
3. Click Upload Local.

For every locally stored Brambleheart character:

- Brambleheart looks for an existing _BH.json file in the linked folder with the same internal character ID.
- If an exact ID match exists, that Drive file is updated.
- If the character has been renamed, the matching Drive file is also renamed to match the current character name.
- If no matching ID exists, a new Drive file is created.

New files use a human-readable filename based on the character name:

CharacterName_BH.json

Unsafe filename characters are removed automatically.

The filename is NOT the character's synchronization identity. The internal character ID inside the JSON file is authoritative.

============================================================
PART 4 - UPDATE LOCAL CHARACTERS FROM DRIVE
============================================================

1. Open Settings > Data & Content > Character Data.
2. Click Update from Drive.

Brambleheart then:

- searches only direct children of the exact linked folder;
- considers only filenames ending in _BH.json;
- validates that the file is a Brambleheart character export;
- matches characters by their internal character ID;
- replaces the local character when an exact ID match exists;
- adds a Drive character when that ID does not exist locally; and
- leaves local characters with no Drive counterpart untouched.

Update from Drive is an explicit replacement operation for exact ID matches. Save or upload any local changes you want to preserve before updating from Drive.

============================================================
FILE FORMAT AND DUPLICATES
============================================================

A valid synced character uses Brambleheart's standard character export format, including:

- format: brambleheart-character
- version: Brambleheart build version
- character.id: the stable internal character ID
- character.name: the visible character name

Files that do not validate as Brambleheart character exports are skipped.

If the linked folder contains two or more valid _BH.json files with the same internal character ID, Brambleheart stops the sync and reports the duplicate ID. Remove or correct the duplicate before trying again. This prevents an arbitrary file from silently winning.

============================================================
DISCONNECTING OR REVOKING ACCESS
============================================================

Disconnect in Brambleheart:
- removes the saved folder pairing from that device;
- does not delete local characters;
- does not delete Drive files; and
- does not by itself remove the service account's Google Drive permission.

To revoke Drive access completely, remove the service-account address from the shared folder's access list in Google Drive. Future Update from Drive and Upload Local operations will then fail because the backend can no longer access the folder.

The temporary BH-LINK line is normally removed automatically as soon as the folder is linked, so it is not a long-term revocation control.

============================================================
TROUBLESHOOTING
============================================================

"Google Drive sync is not configured"
The site owner must configure the three BH_DRIVE_* Vercel Environment Variables and redeploy the site.

"This folder is in My Drive"
Move/create the Brambleheart folder inside a Google Workspace Shared Drive. Normal My Drive does not support this two-way service-account design.

"Service account does not have enough access"
Share the exact folder directly with the service-account email using an edit-capable role that can add and edit files. Check Shared Drive organization policies if external sharing is blocked.

"Folder description must contain..."
Copy the current Folder Link Code from Brambleheart and put the exact BH-LINK line into the folder's Description, then immediately click Link Folder. The line is removed automatically after the link succeeds. If you generated a New Code, the old code no longer matches.

"Duplicate character ID"
Two valid _BH.json files represent the same Brambleheart character. Keep the correct file and remove or replace the duplicate.

Files are not appearing during Update
Confirm all of the following:
- the file is directly inside the linked folder, not a subfolder;
- the filename ends exactly in _BH.json (case-insensitive);
- the file contains a valid Brambleheart character export; and
- the service account still has access to the linked folder.

SECURITY NOTES
- Never publish the service-account private key or BH_DRIVE_LINK_SECRET.
- The BH-LINK folder code is a folder-link proof, not the Google service-account credential, but it should still not be posted publicly without reason.
- Link only a dedicated Brambleheart folder. Do not use a Shared Drive root or unrelated project folder.
- Brambleheart's backend is designed to query only the exact linked folder and only _BH.json character files.

END OF GUIDE
