BRAMBLEHEART CLOUD SYNC — USER INSTRUCTIONS
Beta 0.29

OVERVIEW
Brambleheart stores your active Character Data locally on the device you are using. Cloud Sync is optional and manually controlled.

When you connect Dropbox, Brambleheart uses your own Dropbox account and your own Dropbox storage quota. Dropbox creates an isolated Brambleheart App Folder for the connection. Other Brambleheart users have separate Dropbox storage, and App Folder access does not let Brambleheart browse the rest of your Dropbox.

Only valid Brambleheart character files ending in _BH.json are used by Cloud Sync.

============================================================
CONNECT DROPBOX
============================================================

1. Open Brambleheart.
2. Go to Settings -> Data & Content -> Cloud Sync.
3. Under Workspace Link, choose Connect Dropbox.
4. Sign in to the Dropbox account you want to use if Dropbox asks you to sign in.
5. Approve Brambleheart's requested App Folder access.
6. Dropbox returns you to Brambleheart Settings.
7. Character Data should show CONNECTED.

The Cloud Link Code shown in Brambleheart is OAuth protection for the current browser. Brambleheart sends and verifies it automatically. You do not need to copy or paste the code.

============================================================
UPLOAD LOCAL CHARACTERS
============================================================

Choose Upload Local to send locally stored Brambleheart characters to your Dropbox App Folder.

Character files use names such as:
CharacterName_BH.json

Brambleheart uses the internal character ID inside each file as the synchronization identity, not the visible filename.

- If Dropbox already contains the same character ID, that cloud character file is updated.
- If a character was renamed, Brambleheart can rename the matching cloud file.
- If two different characters would otherwise use the same filename, Brambleheart adds part of the internal character ID so the files remain distinct.

============================================================
UPDATE FROM CLOUD
============================================================

Choose Update from Cloud to read _BH.json files from your Dropbox App Folder.

- Exact character-ID match: the Dropbox copy replaces the local copy.
- New character ID: the Dropbox character is added locally.
- Local character with no Dropbox match: the local character remains on the device.
- Invalid _BH.json file: the file is skipped.
- Duplicate valid cloud files with the same character ID: synchronization stops rather than guessing which file should win.

Save or upload any local changes you want to keep before choosing Update from Cloud for a character that also exists in Dropbox.

============================================================
WHERE DROPBOX STORES THE FILES
============================================================

Dropbox keeps Brambleheart's files inside the App Folder assigned to Brambleheart. In a normal personal Dropbox account, this is visible under the Apps area.

Your Brambleheart character files count against your own Dropbox account's storage quota.

============================================================
MANUAL SYNC ONLY
============================================================

Brambleheart does not continuously watch Dropbox.

Dropbox is contacted only when you explicitly:
- connect Cloud Sync,
- choose Update from Cloud,
- choose Upload Local, or
- disconnect Cloud Sync and Brambleheart attempts to revoke its authorization.

Normal character editing continues to use local Character Data.

============================================================
DISCONNECT DROPBOX
============================================================

Choose Disconnect inside Cloud Sync.

Brambleheart removes the Dropbox connection stored on the current device and attempts to revoke its Dropbox authorization. Existing _BH.json files are not deleted from Dropbox.

If you also want to remove Brambleheart manually from your Dropbox account, use Dropbox's Connected Apps settings.

============================================================
TROUBLESHOOTING
============================================================

CONNECT DROPBOX IS DISABLED OR CLOUD SYNC SAYS NOT CONFIGURED
Cloud Sync is unavailable on the current Brambleheart deployment. There is no Dropbox setting for you to change as a user.

DROPBOX DOES NOT ASK FOR MY PASSWORD
If you are already signed into Dropbox in the current browser, Dropbox may reuse that signed-in session. Confirm that the Dropbox account shown during authorization is the account you want to connect.

UPDATE OR UPLOAD SAYS AUTHORIZATION IS INVALID
Disconnect Cloud Sync in Brambleheart and connect Dropbox again.

A CHARACTER DOES NOT REPLACE THE LOCAL COPY
Cloud replacement uses the internal Brambleheart character ID. Two character files with the same visible name but different internal IDs are different characters.

A FILE IS IGNORED
Only valid Brambleheart character exports ending in _BH.json are used by Cloud Sync.

DROPBOX IS FULL
The Brambleheart App Folder uses your Dropbox account's available storage. Free space in your account or change your own Dropbox storage plan if needed.

============================================================
PRIVACY AND LOCAL DATA
============================================================

- Character Data remains local-first even while Cloud Sync is connected.
- Dropbox App Folder access limits Brambleheart to its assigned app folder.
- Brambleheart stores the Dropbox authorization needed for manual sync locally on the device that you connected.
- Standard Brambleheart JSON import and export continue to work without Dropbox.
- Disconnecting Cloud Sync does not delete your local characters or existing Dropbox character files.
